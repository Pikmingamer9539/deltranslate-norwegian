# deltranslate-norwegian
A deltranslate language pack for Norwegian| En språkpakke for Deltranslate for norsk

# !!! Important | Viktig
This project is no longer being worked on. | Dette prosjektet blir ikke lenger jobbet på.

## How to install | Hvordan installere

Download the file and extract it in your "Lang" folder in your Deltranslate folder. | Last ned filen og pakk den ut i mappen som heter "lang" i Deltranslate-mappen din.
Then, in the menu change the language to "Norsk" and you're done! | Så, i spillmenyen, sett språket til "Norsk" og du er ferdig.
